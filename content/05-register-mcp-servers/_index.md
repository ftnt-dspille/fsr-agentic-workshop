Here FortiSOAR is the caller. You register an outside MCP server (a public docs server, or one you run yourself) so FortiSOAR's own agents can discover its tools and call out to them, under the same safety rules as every other tool. This is the opposite direction from Part 2, where your laptop agent calls into FortiSOAR.
